### What is this project about?
The work on this project was undertaken in June 2024 for a UG Research Scholarship. It builds on my final year project work which can be found [here](https://github.com/Diarmaid-M-H/LanguageProject).
This project takes an agent based approach to model interactions between bilingual speakers of a minority language. A more in depth explanation can be found [here](https://github.com/Diarmaid-M-H/Agent_Based_Language_Model/blob/55285d266302a4c73aa740636f404a828f5c08f4/Research%20Summary.pdf). 

## What is an agent based model? 
An agent based model is a way to simulate complex systems by modelling the actions of individual "agents" as they interact with and influence one another.

## What are these agents modelling?
This project models language interactions between individuals and what language they will use for them, influenced by proficiency, attitude, language convention and network topography.

## What libraries are used?
Networkx, matplotlib, scipy, numpy, pandas.
